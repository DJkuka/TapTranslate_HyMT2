# Tap Translate 1.125 + Hy-MT2 Offline

Проект интеграции локального движка Hy-MT2-1.8B в рабочий Tap Translate 1.125.

## Что добавляется

- В список движков перевода добавляется `Hy-MT2 Offline`.
- В окне настроек появляется строка `Hy-MT2 Offline · GGUF model settings`.
- В менеджере модели можно выбрать GGUF через системный проводник Android. Файл копируется в приватную папку приложения `Android/data/com.tap_to_translate.snap_translate/files/models/`.
- Модель загружается в оперативную память по кнопке или автоматически при первом переводе.
- Перевод выполняется локально через llama.cpp на CPU ARM64.
- Запросы к одному экземпляру модели сериализованы: параллельные переводы не используют один llama.cpp context одновременно.
- Если файл модели не выбран или запуск/перевод Hy-MT2 завершается ошибкой, текущая цепочка переключается на имеющийся в Tap Translate Google Offline Translate (ML Kit).
- APK намеренно остаётся **без подписи**.

Существующие изменения основного APK сохраняются: Tesseract 5.5.1 для английского OCR, авто-заполнение, шрифты, настройки размера текста и остальные предыдущие smali-правки.

## Какую модель выбирать

Используй именно `Hy-MT2-1.8B-GGUF` с вариантом **Q4_K_M** (около 1,13 GB):

https://huggingface.co/tencent/Hy-MT2-1.8B-GGUF

В менеджере модели можно выбрать файл с любым именем: приложение сохранит его под внутренним именем `Hy-MT2-1.8B-Q4_K_M.gguf`.

Не выбирай 2-bit или 1.25-bit файл из других репозиториев/вариантов. Этот интеграционный runtime и готовая AAR рассчитаны на обычный GGUF Q4_K_M. Модель в APK не включается: её нужно один раз импортировать на устройстве.

## Сборка через GitHub Actions

1. Создай отдельный GitHub repository или используй тестовый репозиторий, в котором запускал предыдущий workflow.
2. Помести **всё содержимое этой папки** в корень репозитория, сохранив структуру `.github/workflows`, `app`, `input`, `scripts`, `tools`.
3. Сделай Commit в ветку `main`.
4. Открой вкладку **Actions**, выбери `Build Tap Translate 1.125 with Hy-MT2` и нажми **Run workflow**.
5. После успешной сборки скачай artifact `TapTranslate-1.125-HyMT2-unsigned`.

Workflow сам:
- устанавливает JDK 17, Android SDK и Gradle;
- компилирует вспомогательный runtime APK с зависимостью `dev.ffmpegkit-maintained:llama-android:0.1.1`;
- извлекает из него smali-классы и нативные библиотеки ARM64;
- добавляет их в исходный Tap Translate, патчит список движков, dispatcher, настройки и manifest;
- пересобирает основной APK через apktool 2.11.0 и выполняет zipalign;
- публикует итоговый unsigned APK как artifact.

Используется тот же вариант Android SDK setup, который уже удалось запустить в предыдущем workflow: `android-actions/setup-android@v4`, `cmdline-tools-version: 15859902`, `accept-android-sdk-licenses: true`.

## После установки

1. Подпиши APK своим обычным тестовым ключом и установи его поверх/вместо предыдущей версии согласно обычной процедуре тестирования.
2. Открой настройки Tap Translate и строку `Hy-MT2 Offline · GGUF model settings`.
3. Выбери `Hy-MT2-1.8B-Q4_K_M.gguf`, дождись окончания копирования.
4. Нажми `Загрузить модель в память` и дождись сообщения об успешной загрузке.
5. Вернись в настройки, выбери движок `Hy-MT2 Offline` и проверь перевод короткого текста.

Если не загружать модель вручную, первая операция перевода тоже попытается загрузить её автоматически. При отсутствии модели или ошибке загрузки будет использован Google Offline Translate.

## Ограничения и проверка

- В сборке оставлен только ABI `arm64-v8a`, соответствующий целевому планшету.
- GGUF-файл хранится отдельно от APK. При импорте требуется место примерно под размер модели плюс запас на временный файл.
- Q4_K_M — стандартный K-quant GGUF. Не путай его с 2-bit/1.25-bit STQ-вариантами: для STQ в llama.cpp требуется отдельная поддержка ядра.
- Локально проверена правка smali/ресурсов и успешная пересборка исходного APK с добавленной точкой вызова. Полная сборка helper AAR и выполнение Hy-MT2 на планшете должны быть подтверждены GitHub Actions и последующим тестом на устройстве; заранее утверждать, что модель уже запускалась на планшете, нельзя.
- Если после сборки приложение падает или перевод не выполняется, пришли Logcat с фильтром `TapTranslateHyMT2`, а также строки `AndroidRuntime` за тот же момент.
